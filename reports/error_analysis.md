# 誤差分析

対象モデル: `gradient_boosting` / test 1,280 地点。本ファイルは `src/error_analysis.py` の集計結果から自動生成されています。

- test MAE: **269 円/㎡**, RMSE: 1,132 円/㎡, R²: 0.991, MdAPE: 1.9%
- 参考: テスト地点のうち前年単価が存在する 1,251 地点だけで「前年単価をそのまま予測」した場合の MAE は 684 円/㎡。これは欠損地点を除いた部分集合での値なので、全1,280地点で評価した `model_comparison.md` の `lag` 行（749 円/㎡）とは対象が異なる。

> **MAPE について**: 本データには 0.2 円/㎡ の山林から 14.8 万円/㎡ の銀座まで 5 桁の幅があるため、MAPE（平均絶対誤差率）は**低価格地点の小さな絶対誤差で桁違いに膨らむ**。モデル選択には使わず、**絶対誤差率の中央値**を併記して分布の代表値として読むこと。

## 9. 仮説の検証

### 仮説1: 容積率プレミアムを過小評価している

- 容積率と実測単価の Spearman 相関: 全体 0.608 / 商業系のみ 0.563
- 容積率500%以上の地点（n=221）の平均残差 -691 円/㎡、MAE 905 円/㎡ （全体 MAE 269 円/㎡）
- **判定: 支持される。** 高容積率地点の MAE は全体平均の **3.4 倍**で、平均残差 -691 円/㎡ は「実際の価格の方が高いのに、モデルは低く予測した」ことを意味する。
- 解釈: 学習年（令和7年）の価格水準を主な手がかりにしているため、**上昇率の大きい都心商業地**で系統的に下振れする。容積率そのものより「容積率が高い地点ほど上昇率も高い」という交互作用をモデルが表現できていないことが原因と考えられる。

### 仮説2: 地積が極端に小さい地点で外す

- 地積80㎡以下の地点（n=44）の MAE 503 円/㎡ vs それ以外 261 円/㎡、平均残差 -334 円/㎡
- 小規模地点の実測単価の中央値はそれ以外の **3.06 倍**で、狭い土地ほど㎡あたりが高い（規模の割高効果）。平均残差 -334 円/㎡ は同じ方向の下振れを示す。
- **判定: 支持される。** 小規模地の MAE は 503 円/㎡ で、それ以外の 261 円/㎡ と比べて **1.9 倍**。学習データに同種の地点が少ない（テスト1,280地点中 44 地点）ため、割高プレミアムを学習しきれていない。

### 仮説3: 駅距離が大きい地点ほど外しやすい

- 全体（プールした）相関 — 駅距離 vs 残差: **0.213**、駅距離 vs 実測単価: -0.603
- 交絡の可能性 — 商業系の駅距離の中央値は 230 m・実測単価の中央値 8,449 円/㎡ に対し、その他は 820 m・2,487 円/㎡。**駅に近い地点ほど商業地であり、商業地ほど高価**という関係があるため、全体相関は都市の用途構成を映している可能性がある。
- 市区町村内での駅距離 vs 残差の相関（25市区町村、各20地点以上）: 平均 **0.089** / 中央値 0.111
- **判定: 支持される。** 市区町村内に入れても相関は 0.089 残り（全体の **42%**）。交絡だけで説明できるほど小さくはならず、**駅距離は市区町村内でも誤差と単調に関係している**。残差の符号も正なので、駅から遠い（＝安い）地点で過大に、駅に近い（＝高い）地点で過小に予測する傾向がある。
- 実務的な含意: `station_distance` の効果は市区町村ごとに強さが異なるため、交互作用特徴量か、市区町村単位のモデル化を検討する余地がある。
